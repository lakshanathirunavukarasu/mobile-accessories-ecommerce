# Mobile Accessories E-commerce

A full-stack e-commerce web application developed for online mobile accessories shopping. The system provides a complete shopping experience with product browsing, search functionality, cart management, user authentication, profile management, and payment processing.

## Features

- User registration and login system
- Product listing with search functionality
- Add to cart and Buy Now options
- Dynamic cart management
- User profile page
- Payment page with GPay QR integration
- Delivery address management
- Order confirmation and success page
- Responsive and user-friendly interface

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- PHP

### Database
- MySQL
